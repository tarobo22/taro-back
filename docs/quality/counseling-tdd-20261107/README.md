## 실행 중 보완 기록

- B01 최초 회귀 실행은 DATABASE_URL 누락, 다음 실행은 기존 Windows 임시 폴더 권한으로 실패했다. 사용자 승인에 따라 전용 합성 DB와 새 basetemp를 사용한 뒤 320건이 통과했다. 코드·기존 테스트·기존 임시 폴더 권한은 바꾸지 않았다. 실패 로그도 보존했다.
- B02 최초 RED는 미구현 저장소에서 4건 실패했다. 첫 구현 후 신규 테스트 준비 코드가 읽기 전용 상담 역할로 동의 행을 INSERT하려 하여 2건 실패했다. 사용자가 명시적으로 허용한 뒤 `queued()`의 동의 행 준비만 DB fixture 연결로 이동했다. 모든 assert와 제품 권한은 유지했다. 따라서 B02의 테스트 파일 SHA는 이 승인된 준비 코드 수정에서 달라진다. `B02-store-red` → `B02-store-fixture-correction-green`이 실제 실행 순서이며 최초 실패한 GREEN 로그도 남긴다.
- B04는 B02 신규 테스트 준비 코드 수정 승인을 기다리는 동안 독립 진행했다. 카드·출처 도메인 이후 GPT 어댑터를 먼저 commit/push했으며, 각 커밋의 포함 기능은 독립적으로 검증했다.
