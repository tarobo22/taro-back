# 여운 | 논문 기반 상담 프롬프트 설계

> NeurIPS 2020 RAG와 ACL 2021 ESConv를 검토하고, 개인사전·대화·카드 문맥에 전략별 프롬프트를 결합했다. Strategy 패턴으로 탐색·경청·조언 지침을 분리하고 경청 모드의 불필요한 질문·행동 출력 등을 계약 테스트로 차단했다. 실제 모델 A/B 품질·지연 평가는 미완료이며 가중치 파인튜닝을 수행한 것으로 표기하지 않았다.

## 실제 적용

| 구분 | 구현 | 확인 상태 |
|---|---|---|
| 탐색 | 감정 반영·상황 확인·정정 우선 프롬프트 | 지침·요청 경계 검사 |
| 경청 | 반영 중심 프롬프트, 질문·행동·카드·정보 필드 차단 | 계약 검사 |
| 조언 | 확인한 고민·카드에 연결한 행동 하나 | 행동 개수·기존 근거 계약 검사 |
| 개인사전 RAG | 본인 키워드·최근 대화·추첨 카드 의미 | 기존 격리·근거 검사 유지 |
