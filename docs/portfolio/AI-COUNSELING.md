# 여운 | 논문 기반 상담 프롬프트 설계

> NeurIPS 2020 RAG와 ACL 2021 ESConv를 검토하고, 개인사전·대화·카드 문맥에 전략별 프롬프트를 결합했다. Strategy 패턴으로 탐색·경청·조언 지침을 분리하고 후속 12사례·48회 실제 GPT A/B 평가를 진행했다. Codex AI의 종합 품질 평가는 74.38→78.96점이었으나 최종 상담 응답은 16.0% 느려졌다. 가중치 학습·임상 효과·일반화된 정확도 향상을 수행·입증한 것으로 표기하지 않는다.
